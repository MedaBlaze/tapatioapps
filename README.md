# TapatioApps

Sitio web estático para TapatioApps. No requiere instalar dependencias ni compilar.
Incluye el arte de marca local en `assets/tapatioapps-brand.png` para no depender del sitio de Google para esa imagen.

## Publicar en GitHub Pages

1. Sube estos archivos a la rama principal de tu repositorio de GitHub.
2. Abre **Settings → Pages** en el repositorio.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama principal y la carpeta **/(root)**, y guarda.

GitHub Pages publicará `index.html` desde la raíz del repositorio. Los enlaces a Google Play
y redes sociales ya están configurados en la página.
